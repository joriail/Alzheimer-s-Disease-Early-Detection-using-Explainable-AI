# Alzheimer's Disease Early Detection using Explainable AI

## Overview

An intelligent web-based Clinical Decision Support System (CDSS) for the early detection of Alzheimer's disease using handwriting analysis, Machine Learning, and Explainable AI (XAI). The system analyzes digital handwriting features from the DARWIN dataset to provide accurate predictions with SHAP-based visual explanations, improving transparency and supporting clinical decision-making. :contentReference[oaicite:0]{index=0}

## Features

- Early Alzheimer's disease prediction using handwriting biomarkers.
- Machine learning-based classification.
- Explainable AI (SHAP) for transparent predictions.
- Interactive web dashboard for clinicians and patients.
- Real-time prediction and visualization.
- Feature selection for improved model performance. :contentReference[oaicite:1]{index=1}

## Dataset

- **DARWIN Handwriting Dataset**
- 450 samples
- 174 handwriting features
- Handwriting tasks including copying, graphics, and memory-based writing. :contentReference[oaicite:2]{index=2}
